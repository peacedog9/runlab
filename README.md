# Run Lab

A treadmill interval trainer with a 60-workout library: warm-up, work
blocks, cool-down, with speed and incline changes called out by voice so
you can run with the screen off and your own music on.

This repository serves the web version via GitHub Pages. It is the exact
same single-file app that ships inside the native wrapper; a hash gate
proves the web build and the app build are byte-identical.

- Web version: keep the screen on during a run (browser limitation).
- Installed wrapper: the workout clock runs natively, so cues continue
  with the screen locked and your music playing.

Privacy: no accounts, no analytics, no network requests of any kind. See
[privacy.html](privacy.html).
